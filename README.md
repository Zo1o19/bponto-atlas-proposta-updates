# Atlas Proposta Bponto — Atualizações

Canal público oficial de atualizações assinadas do Atlas Proposta Bponto.

## Segurança

- Manifesto assinado digitalmente com Ed25519.
- Instalador validado por SHA-256 antes da execução.
- O programa permanece funcional quando estiver offline.
- Simulações e configurações locais são preservadas durante a atualização.

Este repositório não contém dados de clientes nem a chave privada de assinatura.
